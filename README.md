## 🌟 Основные возможности

### 🔐 Безопасность и Шифрование

- **Fernet AES-256 Encryption**: Данные авторизации всех подключенных панелей шифруются алгоритмом AES-256 и хранятся в `data/credentials.enc`.
- **Единственный владелец (`AdminMiddleware`)**: Бот реагирует **строго** на запросы указанного `ADMIN_ID`. Запросы от сторонних пользователей игнорируются.
- **Интерактивный мастер первого запуска**: При первом старте бот автоматически запросит необходимые токены и сгенерирует или примет секретный 256-битный ключ шифрования.
- **Мгновенный Импорт / Бэкап (`credentials.enc`)**: Отправьте файл `credentials.enc` боту в Telegram с ключом шифрования в подписи — бот автоматически расшифрует базу панелей, обновит ключ в `.env` и подключит все серверы.
- **Экспорт Бэкапа (`/export` / `/backup`)**: Скачивание зашифрованного файла базы `credentials.enc` с ключом шифрования прямо из бота через кнопку в Настройках или команду `/export`.

---

### 🌐 Поддержка Прокси (HTTP / HTTPS / SOCKS4 / SOCKS5)

- **Прокси для Telegram Bot API (`BOT_PROXY`)**: Позволяет запустить бот через прокси (например, `http://user:pass@host:port` или `socks5://user:pass@host:port`).
- **Прокси для панелей 3x-ui (`PANEL_PROXY`)**: Позволяет отправлять запросы к панелям 3x-ui через прокси-сервер.
- **Полная поддержка SOCKS4/SOCKS5**: Использование библиотеки `aiohttp-socks` для подключения aiogram и `httpx[socks]` для соединения с 3x-ui.

---

### 🤖 Настройки бота и Дашборд панелей (`/menu`)

- **Команда `/menu`**: Открывает централизованный дашборд управления ботом и мониторинга состояния панелей.
- **Мульти-язычность (English 🇬🇧 / Русский 🇷🇺)**: Переключение языка интерфейса в один клик. По умолчанию установлен **English (🇬🇧)**.
- **Мониторинг здоровья всех панелей (Health Check)**: Автоматическое сканирование всех подключенных 3x-ui панелей с отображением доступности (`🟢 Online: N | 🔴 Offline: M`).
- **Центр Управления**: Перенесен экспорт бэкапа `credentials.enc`, смена активного сервера и выбор языка.

---

### 🖥 Мульти-серверность (Поддержка множества панелей)

- **Управление несколькими серверами**: Добавляйте неограниченное количество панелей 3x-ui в один бот.
- **Мгновенное переключение**: Переключайтесь между серверами в один клик через кнопку `🖥 Сервер: [Имя]`.
- **Автоматическое определение имен**: Имя сервера автоматически определяется по IP/Домену (через Reverse DNS), а также доступно ручное переименование (`✏️ Переименовать текущий сервер`).

### 👥 Управление клиентами и Группы подключений (Client Hub & Groups)

- 📜 **Общий список клиентов**: Просмотр всех клиентов по всем инбаундам с пагинацией и статусами `🟢/🔴`.
- 📁 **Выделенный раздел Групп (`📁 Groups`)**: Отдельное меню для удобной фильтрации клиентов по группам панелей (включая `server_connect`).
- ➕ **Мастер добавления клиента**:
  - Выбор инбаунда.
  - Указание Email / Имени.
  - Настройка лимита ГБ.
  - Настройка срока действия в днях.
  - Настройка лимита подключенных устройств (IP limit).
  - **Начальное состояние**: Возможность сразу создать клиента в режиме `🔴 Отключен` (без первичного соединения).
- 📈 **Редактирование лимита трафика**: Изменение лимита ГБ в любое время или установка безлимита (`0`).
- 📅 **Редактирование срока действия**: Продление или смена даты истечения подписки в днях.
- 🌐 **Смена подключения (`🌐 Изменить инбаунд`)**: Перенос клиента в другой инбаунд с сохранением UUID, Email и настроек.
- 🔑 **Ссылка и QR-код**: Мгновенное получение конфигурационной ссылки (`vless://`, `vmess://`, `trojan://`) и сгенерированного QR-кода.
- 🔄 **Управление трафиком и IP**: Сброс использованного трафика клиента и сброс привязанных IP-адресов.
- ⚡ **Перезапуск Xray Core**: Быстрый перезапуск службы Xray прямо из бота.

### 🌐 Протокольно-ориентированный просмотр подключений (Inbounds Technical Cards)

- 🔍 **Универсальная карточка Инбаунда**: Автоматическая адаптация технических деталей под каждый конкретный протокол:
  - **VLESS / VMESS / TROJAN**: Сеть/безопасность, Target, Xver, SNI, ALPN, WS Path/Host, gRPC Service, HTTP Path.
  - **HYSTERIA / HYSTERIA2**: Obfs, лимиты скоростей (Up/Down Mbps), uTLS, SNI, TLS версии (`1.2 / 1.3`), пути к публичным сертификатам (`fullchain.pem`) и приватным ключам (`privkey.pem`).
  - **MTPROTO**: Считывание всех 10 параметров из веб-панели (FakeTLS SNI, Domain Fronting IP:Port, Fronting/Accept PROXY, IP Preference, Debug Log, Max Connections, Xray Routing, Public IPv4/IPv6).
  - **TUN**: Имя интерфейса (`xray0`), MTU, Gateway, DNS, Исходящий интерфейс.
  - **TUNNEL**: Переписание адреса и порта, Разрешенная сеть (TCP/UDP), Follow Redirect.
  - **SHADOWSOCKS / DOKODEMO / SOCKS / HTTP / WIREGUARD**: Полный набор параметров каждого протокола.
- 🔑 **Мульти-уровневый экстрактор uTLS (Fingerprint)**: Извлечение `chrome`, `firefox` и др. из любых вложенных структур JSON.
- 🧹 **Очистка интерфейса**: Условное скрытие деталей Sniffing, если перехват отключен (`🔴 Disabled`).

### 🌊 Полная интеграция с панелями Remnawave (Remnawave Panel Suite)

Бот поддерживает полноценное и глубокое администрирование современных панелей **Remnawave** наравне с 3x-ui. Все функции выстроены в интуитивно понятные цепочки диалогов на двух языках (RU/EN).

#### 1. Мониторинг и Дашборд

- **Главный экран статуса**:
  При переключении на активный сервер Remnawave выводится экспресс-сводка здоровья:
  - 🌐 Адрес хоста и текущий статус (`🟢 Online` / `🔴 Offline`).
  - ⏳ Время непрерывной работы (Uptime) в человекочитаемом формате (`41д 5ч 56м`).
  - 🖥 Технические ресурсы сервера: число ядер CPU, загрузка оперативной памяти (RAM) в GB и процентах.
  - 👥 Статистика пользователей: общее количество, а также разбивка по группам (`🟢 Активные`, `🔴 Отключенные`, `⚠️ Ограниченные`, `⏳ Истекшие`).
  - 📡 Онлайн-метрики: количество клиентов, подключенных прямо сейчас, число активных нод и суммарный прокачанный трафик, автоматически переведенный в **GB** (например, `10.39 GB`).
- **Интерактивный дашборд («📊 Dashboard»)**:
  Отдельный выделенный экран, собирающий расширенную телеметрию с трех системных эндпоинтов API в параллельном режиме:
  - **Bandwidth Usage (Полоса пропускания)**: Детальная сравнительная таблица потребления трафика за Сегодня, 7 дней, 30 дней, календарный месяц и текущий год по сравнению с аналогичными предыдущими периодами (текущий трафик vs прошлый трафик, а также точная разница).
  - **Remnawave Runtime & PM2**: Мониторинг всех запущенных процессов приложения (API, Scheduler, Processor) — общее число процессов, суммарно занятая оперативная память (RSS), используемый Heap и средняя задержка Event Loop.
  - **Процесс-детализация (Runtime Details)**: Точечный аудит каждого процесса в PM2 — отображение PID, распределение Heap-памяти (использовано / всего в % соотношении), RSS, External память, Array Buffers, точные задержки Event Loop (среднее время и 99-й перцентиль P99 в миллисекундах), а также количество активных Handles.

#### 2. Управление клиентами (Users Hub)

- **Интерактивный поиск и списки**: Пагинация списка пользователей с фильтрацией по статусам и возможность мгновенного поиска по имени (username) или Telegram ID.
- **Карточка пользователя**: Полная информация о лимитах (ГБ, срок действия подписки), статус активности, используемый трафик за текущий период и за все время.
- **Автоматическое разрешение Geo-Node (Last Online)**: Бот считывает UUID последней ноды подключения пользователя, сопоставляет его со списком нод панели и выводит название активной ноды вместе с национальным эмодзи-флагом страны размещения прямо в строке активности, например: `🌐 Последняя активность: 22.08.2026 19:14 (🇳🇱 NL-1)`.
- **Управление параметрами подписки**:
  - `🟢 Включить` / `🔴 Отключить` аккаунт пользователя.
  - `⏳ Продлить`: Быстрое продление срока действия подписки на указанное число дней.
  - `✏️ Лимит трафика`: Установка лимита в ГБ или перевод пользователя на безлимитный тариф (`0`).
  - `📱 Лимит HWID`: Изменение максимального числа одновременно подключенных устройств.
  - `🗑 Удалить`: Быстрое удаление учетной записи из панели с каскадной очисткой связей.
- **Экспорт конфигурации xray**: Возможность мгновенной выгрузки xray-профиля пользователя в виде JSON-кода (отправляется в markdown-формате ` ``` ` для удобного копирования) или отдельного скачиваемого `.json`-файла для импорта в клиенты.

#### 3. Управление нодами (Nodes Hub)

- **Технические паспорта нод**: Подробный мониторинг состояния каждой подключенной ноды:
  - Модель процессора и количество доступных ядер.
  - Объем RAM (всего / свободно) с процентным индикатором.
  - Версия операционной системы (OS/Arch) и версия используемого ядра Linux (Kernel).
  - Скорость сетевых интерфейсов (актуальный RX/TX в Mbps) и общий объем прокачанного трафика.
  - Список активных портов входящих соединений (Inbounds) для каждого профиля конфигурации.
- **Администрирование**: Удаленный перезапуск службы ноды, сброс накопленного трафика и изменение конфигурации.

#### 4. Профили и Маршрутизация хостов (Profiles & Hosts)

- **Конфигурационные профили**: Просмотр привязанных xray-профилей и быстрый экспорт их конфигурации.
- **Управление Хостами (Hosts)**: Полный CRUD-контроль точек входа:
  - Тонкая настройка параметров SNI, Host Header, путей (WS Path / gRPC Service), ALPN, Route ID и Fingerprint (uTLS).
  - Быстрое переключение видимости хоста для клиентов (кнопки `🟢 Показать` / `🔴 Скрыть`).
  - Интерактивный мастер создания хоста с пошаговым выбором протокола и привязанного инбаунда.

#### 5. Веб-страницы подписки (Panels Page Configs)

- Мониторинг конфигураций посадочных страниц (subscription landing pages), которые отображаются пользователям при переходе по ссылке подписки.
- Возможность создания страниц с кастомным HTML-кодом, клонирования существующих макетов и удаления неактуальных конфигураций.

## 🛠 Интеграция с API

Бот оснащен двумя асинхронными клиентами для работы с API панелей:

1. **Клиент 3x-ui** ([x_ui/core/api_client.py](x_ui/core/api_client.py)) — поддерживает как **Modern Clients REST API (Sanaei 3x-ui v2.4+)**, так и legacy-эндпоинты.
2. **Клиент Remnawave** ([remnawave/core/api_client.py](remnawave/core/api_client.py)) — асинхронный клиент для работы со всеми контроллерами Remnawave REST API (системные метрики, bandwidth, здоровье процессов, пользователи, ноды, хосты, профили и страницы подписки).

Автоматический повтор сетевых запросов (Auto-Retry) при микро-сбоях соединения.

## 📋 Инструкция по установке и запуску

### 1. Клонирование репозитория и переход в папку

```bash
git clone https://github.com/lackyhy/3XUI-support-bot.git
cd 3XUI-support-bot/
```

### 2. Создание и активация виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip3 install -r requirements.txt
```

### 4. Первый запуск и автоматическая настройка

При первом запуске скрипт автоматически определит отсутствие `.env` файла и запустит интерактивный CLI-мастер в терминале:

```bash
python3 bot.py
```

Вас попросят ввести:

1. **Telegram Bot Token** (полученный у [@BotFather](https://t.me/BotFather)).
2. **Telegram Admin ID** (ваш уникальный числовой ID, например `123123123`).
3. **Ключ шифрования (ENCRYPTION_KEY)**:
   - Нажмите `[Enter]` для авто-генерации 256-битного Fernet ключа.
   - Или введите свою секретную фразу (около 20–25 символов).

Конфигурационный файл `.env` создастся автоматически:

```env
BOT_TOKEN=
ADMIN_ID=
ENCRYPTION_KEY=
```
